### SET UP REQUIREMENTS

Please download the included image.jpg and malformed.csv included with the source code.
Although the main application will still work, these are used for the test cases.
Place the application code in the same directory as your data code, or use absolute paths when
providing the dataset to the application.

### RUNNING THE APPLICATION

To run the main application: `python3 App.py`
To run the test suite: `python3 tests.py`
To run a specific group of tests: `python3 tests.py <test class name>`
    For example: `python3 tests.py TestRuntime`

### NOTE ON RUNTIME TESTS

Runtime tests may have different results running on different machines.
