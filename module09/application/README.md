## ACME Neural Intelligence Compression App

### Requirements

For testing, place the source code files in the same directory as the dataset files, `CS 680 Project Data Set-1.csv`, etc.
For normal use, dataset files need not be in a specific location as long as the proper path is given.

### To Run

To run the automated unit tests: `python3 tests.py`
You may choose to run a specific test suite by specifying its name: `python3 tests.py TestLoadData`

To run the main application in interactive mode: `python3 App.py`
